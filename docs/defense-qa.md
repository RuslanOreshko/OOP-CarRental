# Defense Questions and Answers

## Why did you use the Repository Pattern?

To separate business logic from data access and improve maintainability.


## Why did you use the Strategy Pattern?

To support different pricing algorithms without changing service logic.


## Why use Generics?

To create reusable repository implementations for different entity types.


## Why use JSON persistence?

It provides a simple way to save and restore application state without requiring a database.


## What SOLID principles are used?

* Single Responsibility Principle
* Open/Closed Principle
* Dependency Inversion Principle


## How is the project tested?

Using unit tests, integration tests, and coverage collection.


## What would you improve in the future?

* Database integration
* Authentication
* REST API
* Advanced reporting


## What was the most difficult part?

Designing a maintainable architecture and implementing persistence while keeping the code testable.
